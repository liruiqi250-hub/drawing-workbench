# 图纸工作台 V0.5.4

供同事在自己的 Windows 电脑上独立使用的本地图纸管理工具。界面通过本机浏览器打开，图纸保留在原目录。

## 给同事的最短操作

下载 `DrawingWorkbench-v0.5.4-source.zip` 并解压到一个长期保留的文件夹（例如 `D:\软件\图纸工作台`），将下面这段话和解压文件夹一起交给能操作电脑文件与终端的 AI：

> 请读取这个文件夹里的 AGENTS.md 和 AI安装说明.md，帮我在这台 Windows 电脑安装图纸工作台 V0.5.4，执行安装脚本、验证启动并创建桌面快捷方式。默认索引本机可访问盘符里的 CAD/PDF 图纸，排除系统目录，不移动或删除原文件。DeepSeek 密钥由我稍后在设置页填写。

普通文字聊天机器人不能直接替你运行安装；可使用已获本机文件/终端权限的 Codex、Claude Code、Cursor 等工具。

安装完成后双击桌面“图纸工作台”，浏览器访问 <http://127.0.0.1:17863/>。首次扫描需要时间，已建立的索引会保留；后台运行期间监听保存、修改、重命名。关闭网页后后台仍运行，可从设置启用登录后自动运行。

## 手动安装

支持 Windows 10/11 x64，需要 Windows PowerShell 5.1 和可联网下载环境。首次安装会下载约 60 MB 运行文件，不要求预装 Node、Python 或 CAD，不修改系统 PATH，也不要求管理员权限。

在解压目录打开 PowerShell：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
```

运行环境只安装到当前目录的 `runtime`。脚本固定版本并检查 SHA-256，校验不一致时停止。可重复执行；已有环境检查通过后直接复用。下载失败可检查网络后重试；不需要关闭杀毒软件或永久更改执行策略。

## 功能

- 搜索本机图纸名称、路径、分类、图号、产品、尺寸和已提取 PDF 文字。
- 按项目、类型、格式与订单批次筛选；支持手工分类和可编辑关键词规则。
- 解析 `26-10.29-01 霸王龙4米.dwg` 这类图号，提取订单日期、生产单序号、产品和尺寸；识别展会名称。
- 左侧订单入口按规范化日期倒序显示最近 100 批，同日补零写法合并，字母批次保持独立；顺序不受图纸数量影响。
- 同目录的原图与合法日期时间备份归组；默认显示原图，详情展开备份。不同格式或不同目录不会仅按同名合并，备份来源目录可在设置手工映射。
- Windows 原生目录事件监听；程序需要在后台运行。网络共享的事件速度受服务器和网络影响，另有定期扫描补齐。
- PDF 首页预览和有限文本提取；DWG 缩略图依赖本机可用的 Windows CAD 缩略图处理器，未安装处理器时仍可搜索、定位，可能没有预览。用 CAD 打开图纸仍需要相应 CAD 软件。
- 可选 DeepSeek 自然语言找图与分类建议。默认 AI 关闭且没有密钥，建议需确认后应用，原文件始终不改动。

## 分类与规则确认

详情中的“整组共同分类”作用于同组原图和备份。各物理版本原有人工分类继续保留，可在版本详情查看。迁移时一致的项目、类型和标签可汇总；矛盾值会显示“分类冲突”，必须查看历史值并勾选确认后才能统一。后加入的原图或备份仅继承无冲突的已确认共同分类。

点击“本机规则批量整理”，先预览建议、既有分类、命中规则和冲突，再确认所选组。每批最多 50 组；可以跳过冲突批次继续查看下一批。预览不改分类，确认才写本机索引，文件不改动。规则、组成员或分类变化后，旧预览会失效，请重新预览。

AI 整理默认合并全部已有人工标签。建议中省略的标签继续保留；编辑为删除时会列出差异，只有明确勾选删除确认才替换。合并超过 50 个标签或单项超过 100 字时拒绝保存，请人工编辑后重试。AI 外发元数据有长度上限，因此建议可能省略标签；该上限不会截断本机已有标签。

自然语言找图先在本机建立有限候选，再由 DeepSeek 排序；结果显示代表原图和实际命中版本、字段及片段。共同分类命中会明确标识来源，裁剪掉的可选词提示未展开。它不读取 DWG 几何，也不保证在有限候选中覆盖全盘所有语义相关图纸。

AI 搜索返回格式正确但包含重复项或候选范围外 ID 时，本机按候选白名单过滤并去重，保留有效结果并提示处理数量。非空响应全部无效、格式错误或字段超限仍明确报错；程序不会自动重试付费请求。搜索失败后可手动重试或切回关键词搜索。

## 数据和隐私

每位 Windows 用户的数据默认位于 `%LOCALAPPDATA%\DrawingWorkbench\data`，包含索引、分类、设置、缓存和日志。升级时保留这个目录。发布包不含任何人的图纸、个人索引、密钥或扫描路径设置。

在“设置 → AI”填写自己的 DeepSeek API Key 并启用。密钥由 Windows DPAPI 按当前用户加密，不随索引备份导出。手动使用 AI 时会向 DeepSeek 发送问题和有限的候选图纸名称、目录片段、分类等元数据；勾选 PDF 文字选项才会发送有限 PDF 文字，不上传整份 DWG/PDF。调用产生的费用由配置的 DeepSeek 账号承担。

默认扫描当前电脑可访问的 C～Z 盘符，排除常见系统目录。请在设置调整扫描位置，或添加 `\\服务器\共享文件夹`。没有权限的文件夹会显示扫描提示，不会绕过权限。跨目录备份映射规则由各自用户设置，未预置发布者的私人目录。

## 停止、移走与升级

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\停止图纸工作台.ps1
```

程序只停止来自此源码目录的服务，不强杀其他版本。此包不是系统级安装器；不在 Windows“已安装的应用”中注册。需要移除时先在设置关闭自动启动，再停止服务，移走程序文件夹及对应桌面快捷方式。个人数据目录默认保留；原图纸从未复制到安装目录。

升级时先通过设置备份索引，再正常停止旧版，保留完整个人数据目录及旧程序，将新源码解压到新目录，再执行安装脚本。V0.5.0 起数据目录稳定；更早的版本可能使用程序目录内的 `data`，不要直接覆盖或将他人的 data 导入自己的电脑。从 V0.5.1 及更早版本升级会迁移组分类结构；V0.5.2 升级到 V0.5.4 不改变数据库结构。涉及结构迁移的回退需在停止新版后恢复升级前完整数据副本，再启动旧版，不能直接让旧版写已迁移的数据库。密钥加密文件及用量记录需在本机另行保留，不能打包分享。

## 开发与验证

项目不使用 npm 第三方运行依赖。安装脚本下载官方 Node.js 24.15.0、Python 3.13.13，以及 PyPI 的 Pillow 12.3.0、pypdfium2 5.14.0；许可证保留在运行时目录。运行时不提交到源码仓库。官方来源：[Node.js](https://nodejs.org/dist/v24.15.0/)、[Python](https://www.python.org/ftp/python/3.13.13/)、[Pillow](https://pypi.org/project/pillow/12.3.0/)、[pypdfium2](https://pypi.org/project/pypdfium2/5.14.0/)。

```powershell
$env:DRAWING_WORKBENCH_PYTHON = (Resolve-Path .\runtime\python\python.exe).Path
& .\runtime\node\node.exe --test tests/*.test.js
```

Python 预览单测另需开发依赖 `pypdf`，不属于日常运行依赖。源码 `tools/test_preview.py` 使用合成图纸，不读取用户图纸。更多部署验收见 [AI安装说明.md](AI安装说明.md)。

本版本是单机独立使用模式。多位同事分别安装后，各自使用自己的索引和分类；共享文件夹可以分别接入，尚未实现多人账户和统一分类数据库。
