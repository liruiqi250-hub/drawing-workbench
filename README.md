# 图纸工作台 V0.6.0

供同事在自己的 Windows 11 x64 电脑上独立使用的本地图纸管理软件。安装 EXE 后打开独立桌面窗口，图纸保留在原目录。每个人的索引、规则、分类和 DeepSeek 密钥分别保存在自己的电脑。

## 给同事的最短操作

下载 GitHub 发行页的 **`DrawingWorkbench-Setup-0.6.0-x64.exe`** → 双击安装 → 双击桌面“图纸工作台”。安装包自带 Electron、Node、Python 和 PDF 运行组件，不要求预装开发环境，也不要求管理员权限。首次扫描需要时间，已建立的索引会保留。

关闭窗口后进入系统托盘，继续监听图纸保存；再次双击桌面图标会显示已有窗口。托盘右键可以“显示图纸工作台”或“退出程序”。退出会先检查 AI 状态、备份索引并正常停止本应用后台。设置中的“登录后自动运行”延续后台监听模式，不会强制弹出桌面窗口。

可选完整桌面压缩包 **`DrawingWorkbench-0.6.0-windows-x64.zip`**，解压到长期保留的目录后运行“图纸工作台.exe”。不要直接在 ZIP 内启动。Windows OCR 使用本机系统组件；缺少中文识别组件会提示，见 [第三方组件说明.md](第三方组件说明.md)。DWG 打开仍需要本机 CAD 软件。

安装到当前用户目录，Windows“已安装的应用”中有卸载入口；卸载只移除程序，个人数据与原图继续保留。发布版未配置发布者代码签名，Windows 可能显示来源提示。请从本仓库发行页获取并核对 SHA256，不需要关闭安全软件。当前构建面向 Windows 11 x64，ARM64 未验收。

## 已有版本升级与源码使用

升级前在设置备份索引，正常退出旧后台并保留完整数据副本。旧网页版本可能仍在运行；不同安装目录的后台不会被桌面版擅自终止，请先用旧版本停止脚本正常退出。保留上一版程序和数据副本以便回退。

`DrawingWorkbench-v0.6.0-source.zip` 是开发/AI 维护用源码包，不带二进制运行组件。原有网页模式和安装脚本继续保留：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
```

此脚本安装网页模式的本地运行环境并创建网页入口；桌面 EXE 用户直接运行安装包即可。需要从源码构建独立桌面包时运行 `scripts/build-desktop.ps1`，它按照固定来源与 SHA256 下载组件，锁定 electron-builder 版本，生成 `dist/desktop` 内的 EXE 与 ZIP。构建阶段首次需要联网，普通用户运行安装好的软件无需联网下载组件。

## 功能

- 搜索本机图纸名称、路径、分类、图号、产品、尺寸和已提取 PDF 文字。
- 按项目、类型、格式与订单批次筛选；支持手工分类和可编辑关键词规则。
- 解析 `26-10.29-01 霸王龙4米.dwg` 这类图号，提取订单日期、生产单序号、产品和尺寸；识别展会名称。
- 左侧订单入口按规范化日期倒序显示最近 100 批，同日补零写法合并，字母批次保持独立；顺序不受图纸数量影响。
- 同目录的原图与合法日期时间备份归组；默认显示原图，详情展开备份。不同格式或不同目录不会仅按同名合并，备份来源目录可在设置手工映射。
- Windows 原生目录事件监听；程序需要在后台运行。网络共享的事件速度受服务器和网络影响，另有定期扫描补齐。
- PDF 首页预览、后台逐页文字/尺寸提取与 Windows 本地 OCR；DWG 缩略图依赖本机可用的 Windows CAD 缩略图处理器，未安装处理器时仍可搜索、定位，可能没有预览。用 CAD 打开图纸仍需要相应 CAD 软件。
- 可选 DeepSeek 自然语言找图与分类建议。默认 AI 关闭且没有密钥，建议需确认后应用，原文件始终不改动。

## PDF 过滤、文字与尺寸搜索

默认显示“图纸＋待判断 PDF”，普通 PDF 仅在工作台中隐藏，不删除原文件或原索引。首页“PDF 显示范围”可切换全部 PDF、普通 PDF、待判断 PDF；选择普通或待判断时会切到 PDF 格式。详情展示自动判断依据，可人工指定为图纸、普通文档或待判断，也可恢复自动。人工指定按物理文件身份保存，不会被重建覆盖。

识别综合文件名、目录、图号、标题栏、尺寸与图面路径证据；不是检测到一个数字就判图纸。没有可提取文字、线索不足或普通文档与图纸证据冲突时保留待判断。合同附图可能保持待判断，需要人工核对。

文件名即时进入索引。默认文件名命中图纸关键词且无普通文档关键词冲突时，直接归为图纸并跳过正文/OCR；仅目录命中不会跳过。详情可单独补提取文字和尺寸，设置中关闭跳过后会批量补全，已有完整文字索引保留。其余 PDF 正文由单任务后台队列逐份提取，完成后可搜索图内文字和尺寸。直径符号及明确单位规范化，如 Φ20/Ø20、20 mm/20毫米、500mm/0.5m；R50/45°、图号和无单位数字仍可按文字检索，不自动推断其工程含义。结果附实际命中的文件版本、页码、片段和文字/OCR来源，点页码打开原 PDF 对应页。

扫描件和部分文字转轮廓的 PDF 用 Windows.Media.Ocr 在本机识别，原 PDF 始终只读，不上传图片、不调用 DeepSeek。中文 OCR 会做相邻汉字空格清理，但小字体、旋转文字和尺寸符号可能识别错误；核对原图后使用。无可用 OCR 语言时明确提示，保留待判断。

设置可改默认范围、关键词、后台文字提取/OCR开关、读取页数及OCR页数；默认每份最多30页、OCR最多10页，上限分别100/30。单页最多20000字，全文最多200000字、文件最大256MB；超出范围显示部分提取/上限提示，不能声称已全文覆盖。后台进度与暂停、重新提取入口位于设置。暂停等待当前本地任务结束，不启动下一份；重新提取保留人工指定。

只改PDF规则不会触发全盘扫描；规则可用已提取正文重判，提取选项变化才重新排队。搜索、筛选和AI候选遵守PDF可见性，隐藏版本不能为结果提供正文证据。原图与备份仍按原有精确规则归组；PDF类别与整组人工项目/类型/标签分别保存。

## 分类与规则确认

详情中的“整组共同分类”作用于同组原图和备份。各物理版本原有人工分类继续保留，可在版本详情查看。迁移时一致的项目、类型和标签可汇总；矛盾值会显示“分类冲突”，必须查看历史值并勾选确认后才能统一。后加入的原图或备份仅继承无冲突的已确认共同分类。

点击“本机规则批量整理”，先预览建议、既有分类、命中规则和冲突，再确认所选组。每批最多 50 组；可以跳过冲突批次继续查看下一批。预览不改分类，确认才写本机索引，文件不改动。规则、组成员或分类变化后，旧预览会失效，请重新预览。

AI 整理默认合并全部已有人工标签。建议中省略的标签继续保留；编辑为删除时会列出差异，只有明确勾选删除确认才替换。合并超过 50 个标签或单项超过 100 字时拒绝保存，请人工编辑后重试。AI 外发元数据有长度上限，因此建议可能省略标签；该上限不会截断本机已有标签。

自然语言找图先在本机建立有限候选，再由 DeepSeek 排序；结果显示代表原图和实际命中版本、字段及片段。共同分类命中会明确标识来源，裁剪掉的可选词提示未展开。它不读取 DWG 几何，也不保证在有限候选中覆盖全盘所有语义相关图纸。

AI 搜索返回格式正确但包含重复项或候选范围外 ID 时，本机按候选白名单过滤并去重，保留有效结果并提示处理数量。非空响应全部无效、格式错误或字段超限仍明确报错；程序不会自动重试付费请求。搜索失败后可手动重试或切回关键词搜索。

## 数据和隐私

每位 Windows 用户的数据默认位于 `%LOCALAPPDATA%\DrawingWorkbench\data`，包含索引、分类、设置、缓存和日志。升级时保留这个目录。发布包不含任何人的图纸、个人索引、密钥或扫描路径设置。

在“设置 → AI”填写自己的 DeepSeek API Key 并启用。密钥由 Windows DPAPI 按当前用户加密，不随索引备份导出。手动使用 AI 时会向 DeepSeek 发送问题和有限的候选图纸名称、目录片段、分类等元数据；勾选 PDF 文字选项才会发送有限 PDF 文字，不上传整份 DWG/PDF。调用产生的费用由配置的 DeepSeek 账号承担。

默认扫描当前电脑可访问的 C～Z 盘符，排除常见系统目录。请在设置调整扫描位置，或添加 `\\服务器\共享文件夹`。没有权限的文件夹会显示扫描提示，不会绕过权限。跨目录备份映射规则由各自用户设置，未预置发布者的私人目录。

## 停止与回退

桌面版从系统托盘“退出程序”正常退出。网页模式可使用原目录内的停止脚本。程序只停止来源与个人数据目录可核实的本应用服务，不强杀其他安装版本。

每位用户的数据目录为 `%LOCALAPPDATA%\DrawingWorkbench\data`。升级不覆盖个人数据；回退时先退出新版，保留当前数据，再恢复升级前的完整数据副本并运行旧版。不要让旧版直接写已经发生结构迁移的新数据库。V0.6.0 沿用 V0.5.5 的 PDF 索引结构；更早版本升级涉及的迁移说明见版本记录。密钥加密文件及用量记录只在本机保留，不能打包分享。

## 开发与验证

后端不使用 npm 第三方运行依赖；桌面壳使用 Electron 44.7.2，构建工具 electron-builder 26.15.3 由 desktop/package-lock.json 锁定。安装脚本下载官方 Node.js 24.15.0、Python 3.13.13，以及 PyPI 的 Pillow 12.3.0、pypdfium2 5.14.0；许可证保留在运行时目录。运行时不提交到源码仓库。官方来源：[Node.js](https://nodejs.org/dist/v24.15.0/)、[Python](https://www.python.org/ftp/python/3.13.13/)、[Pillow](https://pypi.org/project/pillow/12.3.0/)、[pypdfium2](https://pypi.org/project/pypdfium2/5.14.0/)。

```powershell
$env:DRAWING_WORKBENCH_PYTHON = (Resolve-Path .\runtime\python\python.exe).Path
& .\runtime\node\node.exe --test tests/*.test.js
```

Python 预览单测另需开发依赖 `pypdf`，不属于日常运行依赖。源码 `tools/test_preview.py`、`tools/test_pdf_index.py` 使用合成图纸，不读取用户图纸。更多部署验收见 [AI安装说明.md](AI安装说明.md)。

本版本是单机独立使用模式。多位同事分别安装后，各自使用自己的索引和分类；共享文件夹可以分别接入，尚未实现多人账户和统一分类数据库。
